**Combined Arms (CAmod) - Simplified Chinese Localization**

This project is an unofficial Simplified Chinese localization modification based on [Inq8/CAmod](https://github.com/Inq8/CAmod)(version 1.08.2).

- Original project: Command & Conquer - Combined Arms / CAmod
- Original authors: Combined Arms contributors
- Modifications: Simplified Chinese localization (UI text, unit descriptions, faction descriptions, hotkey text, encyclopedia text, mission dialogue, map descriptions, etc.)
- License: GPL-3.0
- Upstream links: [ModDB](https://www.moddb.com/mods/command-conquer-combined-arms) | [Discord](https://discord.gg/CxFYWEJ)
